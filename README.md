# 🌦️ MAUSAM – Personalized Weather Website

MAUSAM is a responsive weather website designed to provide personalized, useful, and easy-to-understand weather information for different types of users.

> **Same weather, different needs.**

A farmer, traveller, commuter, and parent may all need different weather information. MAUSAM organizes weather information around the user's needs.

## ✨ Main Features

### 🏠 Personalized Home Page
- Current temperature and weather condition
- Feels-like temperature
- Humidity, wind and pressure
- Weather alerts
- User location
- Personalized weather insights

### 👤 User Profiles

- 🌱 **Farmer** – rainfall, crop and agricultural weather information
- ✈️ **Traveller** – destination weather and travel conditions
- 🚗 **Commuter** – rain, traffic and road-related conditions
- 👨‍👩‍👧 **Parent** – school commute and safety-related weather information

### 🌤️ Forecast
- Today's forecast
- Hourly weather information
- 7-day forecast
- Temperature information
- Weather conditions

### 🔔 Weather Alerts
- Heavy rainfall alerts
- Important weather notifications
- Weather safety information

### 🗺️ Interactive Weather Map
- World map
- Pune location marker
- Interactive zoom and drag
- Weather map concept for future rainfall, temperature, wind and air-quality layers

### ⚙️ Settings
- Location preferences
- Weather alert settings
- Rainfall alert settings
- Language selection
- Profile settings
- Dark-mode option in the UI

## 📱 Responsive Design

MAUSAM is designed for:

- 💻 Laptop / Desktop
- 📱 Mobile Phones

On mobile devices:

- The website scrolls vertically.
- Wide sections such as profile cards and forecast rows can be swiped horizontally.
- Images and cards resize to fit the screen.
- Navigation adapts to smaller screens.

## 🛠️ Technologies Used

- **HTML5**
- **CSS3**
- **Responsive CSS / Media Queries**
